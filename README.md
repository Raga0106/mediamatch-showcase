# MediaMatch 專案展示網站

這份檔案用來對朋友、工程師、設計師與潛在協作者展示 MediaMatch 的產品願景。

## 線上展示

- 網站：<https://raga0106.github.io/mediamatch-showcase/>
- 儲存庫：<https://github.com/Raga0106/mediamatch-showcase>
- 部署來源：`main` 分支根目錄，透過 GitHub Pages 發布；更新網站檔案並推送後會自動更新網站。
- 分享網址已設定。聯絡信箱尚未填寫，訪客仍可複製參與訊息。

## 如何開啟

將 `index.html`、`creators.js`、`creators.css`、`discovery.js`、`discovery.css` 放在同一個資料夾，直接雙擊 `index.html` 即可，無需 npm、API Key 或資料庫。手機與電腦都支援。設計靈感區的官方參考連結需要網路連線。

## 如何分享成真正網址（GitHub Pages）

1. 新增一個公開的 GitHub 儲存庫（例如 `mediamatch-showcase`）。
2. 將上述五個網站檔案和 `.nojekyll` 上傳到儲存庫 `main` 分支根目錄。
3. 打開 Settings → Pages → Build and deployment → Deploy from a branch，選擇 `main` / `(root)`。
4. 網站上線後，將網址貼給朋友或放到社群簡介。

## 可選設定：聯絡方式

分享網址已設定。在 `index.html` 的靠近底部搜尋 `PROJECT_CONFIG`，可按需補上聯絡信箱：

```javascript
const PROJECT_CONFIG = {
  contactEmail: '你的聯絡信箱',
  projectUrl: 'https://你的展示網站網址',
  githubUrl: 'https://github.com/你的專案網址'
};
```

- 設定 `contactEmail` 後，點擊「一起打造」會出現可直接寄信的按鈕。
- 如果沒有設定聯絡信箱，訪客仍可產生並複製參與訊息，透過你傳送此頁面的管道回覆。
- `projectUrl` 會用於分享與複製參與訊息。設定後才能讓本機開啟的網頁分享正式網址。
- `githubUrl` 為保留的設定欄位，未連接到對外按鈕；如需放出程式碼頁面請另行新增連結。

## 目前功能的真實狀態

- v1.3 提供作品探索與創作者探索兩種滑動模式，共用本次探索的偏好訊號，各自保留卡片與操作進度。
- 作品喜好會影響相關創作者推薦；創作者喜好也會影響其他來源的作品推薦。使用小型虛構內容池與前端規則計算，並展示推薦原因。
- 配對支援按鈕、方向鍵、左右拖曳、作品收藏、各模式撤銷與本輪回顧。
- 喜歡創作者不等於追蹤；追蹤必須明確操作，不會因查看詳情、推薦或切換模式自動加入清單。
- 創作者清單保留主題、平台、語言篩選、追蹤／取消追蹤、已追蹤清單及代表作品的讀後回饋。
- 偏好分數僅示意個人與來源的適合程度，不是客觀品質、專業度或內容可信度評分。
- 兩模式的後續候選會依共用偏好重新排序，目前正在看的卡片保持不變。這不是完整的正式推薦模型。
- 顯示的是**前端概念 Demo**；卡片資料是示意文案，不是真實平台 API 內容。
- 尚未有使用者登入、正式推薦後端、跨平台抓取服務。
- 所有操作只存在於本次頁面記憶體；重新整理即重設，不會送出或持久化訪客資料。
- MediaMatch 內的追蹤與第三方平台訂閱分開；本頁不會操作外部帳號。

## 推薦邏輯驗證

使用 Node.js 執行 `node --test discovery.test.js swipe.test.js`。測試涵蓋模式進度、中性略過、明確負回饋、喜歡與追蹤分離、雙向跨來源推薦、已看內容排除、撤銷與重設行為，以及手機觸控捕捉轉移、左右滑動、上下捲動與取消手勢。手勢測試重播瀏覽器事件順序，並不等於實體手機測試；推薦測試也不代表正式推薦品質已完成評估。

v1.3.1 修正手機從卡片內文字／圖案開始拖曳時，子元素的 `lostpointercapture` 冒泡導致手勢被清除的問題。卡片在按下時立即捕捉指標，僅處理卡片本身的捕捉遺失，並保留垂直捲動。

v1.3.2 參照 v1.2 的滑動節奏：卡片完整跟隨手指，標記隨距離漸顯；超過 100px 放開後，從原位置飛出、淡出 280ms，再讓下一張入場。未達距離則回彈，換卡保留卡槽高度。動畫期間鎖定操作，避免連按重複記錄，並遵循系統的減少動態效果設定。手勢測試另涵蓋超過 130px 的跟手位移、逐幀合併、放開時保留位置及取消時清除待更新畫面。
